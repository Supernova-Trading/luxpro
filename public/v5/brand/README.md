# LuxPro brand · option A "Coachline" (chosen by the owner, 2026-10-06)

The name set wide in Newsreader capitals, with one gold pinstripe beneath it,
like the hand-painted coachline on a coachbuilt car. Letters are outlined, so
the files look the same everywhere without the font installed.

| File | Use |
|---|---|
| `luxpro-wordmark-on-dark.svg` | The logo on obsidian / any dark background (Newsreader display cut) |
| `luxpro-wordmark-on-light.svg` | The logo on ivory, white, printed cards and stickers |
| `luxpro-wordmark-small.svg` | Below ~200 px wide (text cut, a little sturdier); letters use `currentColor` |
| `luxpro-icon.svg`, `luxpro-icon-512.png` | App / social icon: LP + pinstripe on obsidian, rounded |
| `luxpro-icon-square.svg` | Square master for Android, which masks its own shape |

**Colours** — obsidian `#100E0B`, ink `#F5F3EF` (on dark) / `#1B1813` (on light), gold `#C8A84B`.
The pinstripe is always gold; the letters are never gold.

**Clear space** — keep at least the height of the capital letters free on every
side (ui-ux-pro-max brand/references/logo-usage-rules.md, "Clear Space").

**Minimum size** — wordmark 120 px wide on screen / 35 mm in print; icon 24 px
(ui-ux-pro-max logo-usage-rules.md, "Minimum Size").

**Don't** — stretch, recolour the letters, add shadows, glows or gradients, put
it on busy photos without the dark band, or draw the stripe without the name.
